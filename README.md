# Gray's Lemonade website — rebuilt starter

A self-contained, responsive website. No frameworks, dependencies, build tools, external images, or network requests.

## Preview locally
Double-click `index.html` to open it in Chrome, Edge, Firefox, or Safari.

## Publish with GitHub Pages
1. Create a new public GitHub repository, such as `grays-lemonade`.
2. Upload `index.html` to the repository root and commit it.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the website and follow the displayed URL.

## Customize
- Colors: change `--green`, `--yellow`, and other variables near the beginning of `index.html`.
- Logo: replace the text brand and lemon artwork when the official logo is available.
- Flavors: update the three cards in the `#flavors` section.
- Events: replace the placeholder in the `#events` section.
- Contact: replace the placeholder spans with real links once the email and social URLs are supplied.

No ordering, payments, or administrative event editing is included in this initial static version.
