# Gray’s Lemonade website — official branding update

Open `index.html` in a browser or upload the **contents** of this folder to the root of a GitHub Pages repository. Keep the `assets` folder alongside `index.html`.

## Official logo assets
- `assets/GL_FullPrimaryColourLogo.svg` — hero logo on light background
- `assets/GL_ReversePrimaryLogo.svg` — navigation/footer on dark background
- `assets/GL_FullColourSymbolMark.svg` — favicon

Assets are copied unchanged from the supplied official RGB/digital files. Brand colors and fonts follow the supplied style guide. Events, social links, email, and full flavor menu remain placeholders pending confirmation.
